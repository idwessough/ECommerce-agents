# Test technique - Développeur IA : Agent d'analyse de

# marché e-commerce

## Objectif

Ce test est élaboré pour mettre en lumière votre expertise dans le développement
d'agents intelligents utilisant des modèles de langage et l'orchestration d'outils. Il
vise à évaluer votre capacité à concevoir et implémenter des systèmes d'IA
agentiques complexes.

Nous considérons cet exercice comme le point de départ d'une discussion. **La
qualité de la réflexion et la clarté de vos justifications sont plus importantes
que la quantité de fonctionnalités implémentées.**

## Principes directeurs

- **Focus sur l'orchestration :** L'objectif principal est d'évaluer votre capacité à
    faire collaborer des outils via un agent. La perfection de chaque outil
    individuel est secondaire.
- **Clarté avant complexité :** Une solution simple, bien expliquée et robuste
    est préférable à une solution complexe et inachevée.
- **Justifiez vos choix :** Le fichier README.md est aussi important que le code.
    C'est votre espace pour expliquer votre raisonnement.

## Contexte et mise en situation

Nous développons un système d'intelligence de marché pour nos clients e-
commerce. L'objectif est de leur fournir des analyses de marché automatisées et
personnalisées basées sur des données en temps réel.

Nous avons identifié le besoin d'un agent intelligent capable d'orchestrer plusieurs
outils d'analyse pour produire des rapports stratégiques complets sur des produits
ou marchés spécifiques.

Pour ce projet, vous développerez un agent d'analyse de marché qui utilise
plusieurs outils spécialisés pour collecter des données produit, analyser la
concurrence, évaluer le sentiment client, et générer des recommandations
business.


**Important:**

- Créez un nouveau dépôt Git pour votre solution
- Un fichier README.md doit être fourni pour :
    o guider l'utilisateur dans l'installation et l'utilisation (étapes 1 à 3)
    o répondre aux questions théoriques (étapes 4 à 7)
- Limitez votre travail de programmation aux **étapes 1 à 3** incluses
- Votre code doit être exécutable et démontrable

## Étapes du test

**1. Setup et architecture de base**

Créez l'architecture fondamentale de votre agent d'analyse de marché :

- **Approche framework** : Choisissez et configurez un framework d'agents
    (LangGraph, CrewAI, Google ADK, ou autre)
- **OU approche native** : Implémentez votre propre système d'orchestration
    directement en Python
- Implémentez l'agent orchestrateur principal
- Définissez l'interface API REST pour recevoir les demandes d'analyse
- Créez la structure modulaire pour les di]érents outils
- **Containerisez votre solution avec Docker** pour faciliter le déploiement et
    l'évaluation

_Note: Les deux approches sont acceptées. Justifiez votre choix dans votre
documentation._

_Design de l'API : Vous êtes libre de concevoir l'interface API qui vous semble la plus
appropriée pour ce cas d'usage._

**2. Implémentation des outils spécialisés**

Développez au minimum **3 outils** parmi les suivants (vous pouvez utiliser des APIs
mock ou des données simulées) :

**Outils Suggérés:**


- **Web Scraper Tool** : Collecte des prix et informations produit sur di]érentes
    plateformes
- **Sentiment Analyzer Tool** : Analyse les avis clients et extrait des insights
- **Market Trend Analyzer Tool** : Analyse les tendances de prix et de popularité
- **Report Generator Tool** : Compile les données en rapport structuré avec

**Attentes qualité:**

L'implémentation doit respecter les standards de production avec une architecture
modulaire, une gestion appropriée des erreurs, et une facilité de maintenance et
débogage.

**3. Tests et validation**

Implémentez des tests unitaires couvrant :

- Fonctionnement des outils individuels

_Choisissez judicieusement des tests essentiels sans exagérer leur nombre._

## FAQ

**Quel framework d'agents utiliser?**

Vous avez le choix entre :

- **Frameworks existants** : LangGraph, CrewAI, Google ADK, AutoGen, etc.
- **Implémentation native** : Développer votre propre système d'orchestration
    en Python

L'important est de justifier votre choix et de démontrer votre maîtrise de
l'orchestration d'agents. Une solution native bien conçue peut être tout aussi
valorisée qu'un framework établi.

**Comment gérer les APIs payantes?**

Vous avez plusieurs options :

- **Services gratuits/peu coûteux** : DeepSeek, OpenRouter, Groq, Ollama
    local, comptes trial OpenAI/Anthropic
- **APIs mock** ou données simulées pour les démonstrations

L'important est de démontrer l'architecture et les patterns, pas de dépenser de
l'argent.

**Comment tester le système?**

Créez des exemples concrets avec des produits réels (iPhone, Nike Air Max, etc.) et
montrez les rapports générés. Vous pouvez utiliser des données simulées si
nécessaire.

**Faut-il déployer en production?**

Non, une démonstration locale est su]isante. La solution doit être containerisée
avec Docker pour faciliter l'évaluation et garantir la reproductibilité.
